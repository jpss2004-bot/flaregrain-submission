(System design)How Flaregrain is built

From NASA’s sources to the page in five layers, plus the path a live model reading takes. Every number below comes from the team’s build and evaluation files. The full system runs in the live demo; this site carries its 13 hand-checked records.

Live Explain

How a live reading reaches the page

On Compare, the three starter pairs can ask the team’s model for a fresh explanation. Only checked sentences reach the page, labelled “Flaregrain reading · not NASA evidence”, and only if they are for the pair asked and match this site’s records. Otherwise the saved comparison stays.

Compare→Vercel→Funnel→Mac mini proxy→qwen3:4b→checker→fingerprint→Compare

3
starter pairs, in either order: B1/S1, B1/B10, FLEX-002/S31
40 s
longest wait in all, then the saved comparison stays
6 / hour
fresh answers, shared by every visitor to the site
Each step
Compare
Sends only the two record IDs of a starter pair.
Vercel
Asks the proxy’s health first, for up to 4 s. If it is off or this hour’s answers are used, the saved comparison comes back at once.
Funnel
Carries the request to the team’s Mac mini. It is open only at set hours.
Proxy
Allows 6 fresh answers an hour, one at a time. It keeps each pair’s checked answer and sends it again at once; a reused answer doesn’t count.
qwen3:4b
Writes sentences that cite the pair’s record fields, at temperature 0. A fresh answer takes about 13 to 14 s on the Mac mini and about 4 s more to reach the page.
Checker
Keeps a sentence only if it matches the fields it cites. Removed sentences are counted, not shown.
Fingerprint
Vercel keeps the answer only if it names the pair asked and its facts fingerprint matches this site’s records. A mismatch, an error or 40 s without an answer leaves the saved comparison with a short status.
Compare
Shows the kept sentences as Flaregrain’s reading, and says when a reused answer was written.

The five layers · what goes in, what comes out, how it’s checked

  1. 01

    NASA sources and intake

    Fetches NASA’s Physical Sciences Informatics (PSI) combustion repository and the investigators’ report PDFs, and keeps a checksum for every file it reads. Raw NASA tables are linked, not copied.

    2,009

    9

    In, out, checked
    Goes in
    NASA’s PSI combustion records and experiment tables, and 9 NASA technical reports from NTRS.
    Comes out
    24 investigations, 2,009 table rows and the report text, each file with its checksum.
    Checked
    Every file is checksummed and every record’s licence is read. PSI-10’s licence field is blank; that is recorded as a data issue and disclosed rather than assumed.
    Measured
    By area: extinction 8 investigations (1,055 rows), flammability 7 (290), fundamentals 3 (76), detection 6 (588).

  2. 02

    Normalized data

    Every printed value becomes one normalized value with its unit and its source cell. Each value carries its provenance: checked NASA record PSI table row Flaregrain model or reading context, plus flagged and disputed states. Where two NASA sources disagree, both values stay visible.

    24,573
    normalized values
    13
    hand-checked NASA records, 11 of them comparable runs
    575
    table values flagged, each with the reading the team takes
    In, out, checked
    Goes in
    The PSI table rows and the report pages.
    Comes out
    24,573 values, each with its original unit and table row, and 13 hand-checked records with a report page for every value. This site’s 11 comparable runs make 110 Compare pairs.
    Checked
    Flag rules for printed values that read as something else: a percent 100 times too large, spreadsheet auto-fill damage, a missing decimal point, length and width swapped, a header that lost a subscript, a missing or wrong unit, and implausible values. The printed value is kept and the flag says why.
    Measured
    575 flagged values and 13 record-level issues. An overnight sweep proposed 861 candidates for a second reading; a cross-check against the report text found both known Saffire II disputes on its own.

    Questioned values get a second reading before they are published. Example: Saffire I-1’s sample thickness reads 0.37 mm in the NASA report but sits under a “cm” column heading in the PSI table, so both are shown.

    Codebuild_dashboard_catalog.py build_issues_summary.py

  3. 03

    Retrieval and ranking

    Cuts the report PDFs into passages and ranks investigations for a plain-language question by rules: names, materials, conditions and outcomes. It is measured on a draft set of 30 questions, each asked four ways (plain, technical, short and misspelled).

    1,595
    report passages from the 9 PDFs
    0.850
    recall@5, rules only
    0.833
    hit@1, rules only
    In, out, checked
    Goes in
    A plain-language question, the 24 investigations and the report text.
    Comes out
    Investigations ranked by rules, and report passages to quote with their page. This site publishes 1,321 passages from the five NASA-series documents and links the four papers by page.
    Checked
    120 wordings: 30 questions asked four ways. 108 have an expected answer and are scored; the other 12 should get none.
    Measured
    Rules only: recall@5 0.850 and hit@1 0.833. By wording, hit@1 runs from 0.741 (misspelled) to 0.926 (short).

    With the live model added, an earlier overnight run measured hit@1 0.806 and recall@5 0.839. The model returned a reading for only 22 of the 120 wordings in that run, so it isn’t a full model-ranking result; the rules-only scores are the ones the team stands behind. An earlier script counted hidden rows left over from the previous question and inflated scores to 0.861–0.875; the numbers here are the corrected ones.

  4. 04

    Sentence checker

    Every sentence the model writes is kept only if it matches the record fields it cites. Numbers, units, record names and words are checked against those fields. Sentences that state a disputed value as fact, add a cause, or cite nothing are removed.

    139
    saved explanations: 492 sentences kept, 270 removed
    343,758
    synthetic test sentences, over 55 record pairs
    0
    misses for wrong numbers, wrong records, cause words, missing citations and disputed values
    920 → 240
    wrong-unit misses per sentence framing, after two fixes
    In, out, checked
    Goes in
    Sentences qwen3:4b writes about a pair of records, each citing the record fields it uses.
    Comes out
    Only the sentences that pass. Removed sentences are counted with their reason. A saved or live answer also carries the facts fingerprint of the records it was written from.
    Checked
    A stress test of 343,758 synthetic sentences over 55 record pairs, each made to pass or fail on purpose.
    Measured
    0 misses for wrong numbers, the other record’s fact, cause words, no citation and disputed values. Wrong-unit misses fell from 920 to 240 per framing.

    The saved explanations were written by qwen3:4b (Ollama 0.40.16) and kept only where they passed. The stress test was first run on the team’s Mac mini; its harness, checker_stress.mjs, is in the checks folder. Known gap: invented details that reuse words from the cited fields often pass. In the same test, 19,520 of 23,040 per framing did. That is why model text is always labelled as Flaregrain’s reading and never styled as NASA evidence.

  5. 05

    Interface

    Nora’s Ask, Compare, Evidence and Browse. Every answer links to the NASA page it came from. Model text carries the label “Flaregrain reading · not NASA evidence”. The model, qwen3:4b, runs locally on the team’s Mac mini behind a small proxy; the proxy runs only there and isn’t in this repository. The model is shown live in the demo. This public site shows saved, checked text, and live readings for the three starter pairs on Compare.

    In, out, checked
    Goes in
    The checked records, the prepared comparisons, the saved explanations and, for the starter pairs, live readings.
    Comes out
    Ask, Compare, Evidence and Browse, with the source page beside every value. Nothing needs a sign-in.
    Checked
    Model text always carries its label. A live reading must match the pair and the facts fingerprint, or the saved comparison stays. The build and data checks run before each release.
    Measured
    This site: 13 checked records, 11 comparable runs, 110 pairs, 39 saved explanations.
