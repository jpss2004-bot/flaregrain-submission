# Comparing two airflow shutoff observations

Start with a question: **How long did the flame take to go out after airflow stopped?** Follow each observation to its source and check which part of the test each time value describes.

| Test | Observation after airflow shutoff | Where to check |
| --- | --- | --- |
| BASS-II B1, sample 147 | The flame went out quickly after airflow was stopped. The table gives a qualitative observation. | [NASA BASS-II summary, Table A.1, PDF p. 111](https://ntrs.nasa.gov/api/citations/20210011385/downloads/TM-20210011385.pdf#page=111) |
| Saffire I-1, wide SIBAL fabric in concurrent flow | The investigators describe the flame going out immediately when airflow stopped at the end of the run. The 420 seconds is the test duration up to shutoff. | [NASA Saffire results, PDF pp. 14–16](https://ntrs.nasa.gov/api/citations/20170008805/downloads/20170008805.pdf#page=16) |

Both observations describe prompt extinction in their respective tests. NASA’s Table A.1 row for B1 and the Saffire results page give no elapsed time from shutoff to extinction. The [BASS-II report (PDF p. 21)](https://ntrs.nasa.gov/api/citations/20210011385/downloads/TM-20210011385.pdf#page=21) describes a test where the flow was cut off abruptly and the flame went out within 2 s; it does not name the test. BASS-II B1 used PMMA film with opposed flow. Saffire I-1 used cotton–fiberglass fabric with concurrent flow. Keep the conditions beside each observation when comparing them.

This example illustrates Flaregrain’s comparison design: put the observations and their source links side by side, and show where an exact value is unavailable. The original wording and figures remain in the linked reports.
