# Flaregrain

Flaregrain answers plain-language questions about NASA's microgravity fire experiments, for fire safety in spacecraft and in Moon and Mars habitats. Every NASA value links to the report page or table it came from.

Built by Sparkline Foundry for the NASA Space Apps 2026 challenge "Flame in Freefall", at NASA Space Apps Halifax.
